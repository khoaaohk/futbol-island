# Six prototype review and targeted storyboard fixes

**Status: not visually approved. No further animation changes are made by this review.**

Applied `ART_DIRECTION.md`, the installed art-director skill (DIRECT mode), and storyboard skill (review/fixing mode). Scope is the current continuous versions of Reset, Loss, Empathy, Quiet Lantern, Boat and Weather, and More Than a Shirt. Evidence is the current source, the six phone transition-neighborhood sheets, the earlier desktop compositions, and the complete Reset recording. This is not a claim that all six complete movies have passed the audio-on/audio-off review gate; only Reset currently has a complete narrated recording in this review set.

The useful improvement is spatial continuity. The remaining main failure is **motion without a clear cause and result**. A camera can now travel smoothly through a world while the narration still does the explaining alone. The former moment count and exact boundary tests do not resolve that failure.

## Direction verdict

Task: make the narrated mental concepts visible to a developing football player without requiring the captions to explain what the shapes mean.

Intent: understandable agency, care and room to learn. Grounded vocabulary: ball, cropped boot/hand, flexible branch, water/result paper, pigment, lamp, sail, shirt. Named default to reject: **a centered metaphor icon enlarged and reduced while voice-over supplies the meaning**. Current camera tracks still reach for that default in several passages.

Shape/texture: one cut-paper and screen-print family, with clean large silhouettes and restrained grain. Do not add illustration detail until the action reads. Preserve the cream/navy/cobalt/orange/pink/gold vocabulary, but assign roles per film. Decorative ground stripes and pressure scribbles must not compete with the action.

Opening thesis: begin with the film's specific problem and a visible consequence, not a neutral object portrait. Swap test: partial failure—an isolated lamp, boat or shirt could currently carry several unrelated voice-overs without the illustration changing. The fixes below bind actions to these scripts.

### Findings, worst first

1. **[Subject keeper / serving the work] Weather currently weakens the wind during the breathing passage.** That can imply that managing a feeling changes the external weather. Keep the wind's direction and strength visibly continuous while only sail angle, line tension and boat response change.
2. **[Reference keeper / subject keeper] Reset's tree, roots and large trunk crops borrow Grit's growth imagery.** The script is about flexibility and choosing a next response, not stronger roots or growth. Make the flexible branch's deflection and recovery the signature; treat the trunk/ground as stable geography. Use the same ball for the next-action passage.
3. **[Shape director / serving the work] Loss's intact orange disc has no established meaning.** It cannot by itself communicate worth or continued respect. Establish cropped supporting hands before the result is shown, then keep their care visibly unchanged when the score moves aside.
4. **[Light & focus director] The lanterns light on a schedule without an observable act of noticing or a response.** Make light reveal one actual obstacle/receiving space, show the ball using that information, then show a reply from another lamp that changes the first light's direction.
5. **[World-keeper / subject keeper] Shirt expansion currently looks like a growing garment with orbiting icons.** Keep the shirt's physical size stable. Reveal a larger surrounding world through a seam/fold; its football role is one part of the composition.
6. **[Shape director / serving the work] Empathy's pools overlap, but the brush does not visibly wait for or respond to the other pool.** A question must produce a visible reply before support enters. Respecting quiet must visibly stop the approach and leave space.

Verdict: one material world per film, but several passages still fail the explanatory test. The most valuable next change is a readable **cause → action → result** in the weakest passage, not another camera move.

## Fix storyboards

Times below are absolute movie times from the existing chapter schedule. Spoken cues are exact script excerpts. Finer action starts should use the existing word-onset file when implementing; do not retime the narration. Keep meaningful objects in the phone art window (approximately x45–345, y190–500 at390×844), above the caption tray. Crop for emphasis only while the action and its target remain identifiable.

### RESET-A — flexibility under pressure (10.00–20.00 s)

| Field | Decision |
|---|---|
| Spoken cue | “Imagine a flexible branch in the wind. It bends under pressure, then finds balance.” |
| Meaning | Strength can include yielding and recovering; it is not rigid resistance. |
| Visible cause/result | A gust meets the same branch tip; its bend travels along the wood, then it recovers while the gust passes. No roots grow. |
| Action sequence | 1. Follow the ball's curved motion upward into the branch's existing curve. 2. Hold the whole branch tip and incoming gust together. 3. Gust presses the leaf; branch visibly deflects. 4. Track the bend toward the trunk without losing the tip's direction. 5. Pull back as the same branch rebounds, with a short result hold. |
| Framing | Start medium-wide; push to the flexing joint only after force is visible; finish with the full bent-to-balanced silhouette. Avoid a frame containing only a white trunk stripe. |
| Handoff | The gust's constricted line remains beside the branch and becomes the feeling/breath passage; same colour, location and travel direction. |
| Phone composition | Tip, gust contact and flex point stay in the central art window; trunk can extend beyond frame as context. |

## Production order and review check

Fix WEATHER-A's causal error and RESET-A/B's off-topic focus first. Each is a bounded passage, not a new renderer. Then test LANTERN-B and EMPATHY-B without sound: the other object's response must visibly change the first object's action. Replace LOSS-A's undefined symbol before polishing its texture. Finally keep SHIRT-A's scale explanation while removing garment growth.

For each fix: preserve existing object identity and geography; implement only the storyboarded change; capture the full passage with several seconds of context on both sides; review at390×844 and1440×900 with audio, then muted. Ask whether the viewer can identify the cause, the choice and the result. Passing code checks does not answer that question.
